Development Process

Selected Process Model

The Digital Evidence Case Tracker will use Scrum as its Agile development model. Scrum will organize the project into short sprints, with project requirements represented as prioritized user stories on a GitHub Project board. This approach allows features and screen requirements to be adjusted in response to professor feedback received throughout the semester.

Product Backlog

The product backlog contains eight user stories covering case creation, case searching, evidence documentation, identifying information, chain-of-custody records, evidence status and location updates, and case-summary generation.

Sprint 1

Sprint length: Two weeks

Sprint goal: Create the basic case and evidence-management foundation so an investigator can open a case and document its digital evidence.

Selected user stories:

As an investigator, I want to create a case so that I can organize digital evidence under a specific investigation.

As an investigator, I want to add a digital evidence item to a case so that computers, mobile devices, storage devices, and forensic images are documented.

As an investigator, I want to record identifying details for evidence so that each item can be distinguished and tracked.
