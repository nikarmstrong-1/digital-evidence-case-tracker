# Digital Evidence Case Tracker

## Project Owner

Nikolas Armstrong

## Project Abstract

The Digital Evidence Case Tracker is designed to help investigators organize evidence collected during cybersecurity and criminal investigations. The application will allow users to create cases and add digital evidence, such as computers, mobile devices, storage devices, and forensic images, while keeping important case information organized in one location. It will also maintain a documented chain of custody with timestamps, allowing users to see when evidence was accessed, who accessed it, and what actions were performed. The system is intended for investigators and other professionals responsible for securely documenting and managing digital evidence.
